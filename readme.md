# My Projects

Small tools and experiments I build, mostly AI-powered utilities for Linux.
Each project lives in its own folder with its own README and setup instructions.

## About

I like building practical tools that make everyday computing easier, and I
share them here so others can use, fork, or learn from them.

## Using a project

1. Open the project's folder.
2. Follow the install steps in its README.
3. Open an issue if something breaks or you have an idea.

## Feedback

Issues and suggestions are welcome. If a project is useful to you, a star helps
others find it.
